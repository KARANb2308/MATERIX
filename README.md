# MATERIX

เว็บค้นหา **ร้านวัสดุก่อสร้าง และร้านเช่าอุปกรณ์/เครื่องมือก่อสร้าง** ใกล้ตัวคุณ หรือที่ตำแหน่งไหนก็ได้ที่เลือกเอง
พร้อมเบอร์โทร LINE Facebook เว็บไซต์ เวลาเปิด-ปิด และปุ่มนำทางด้วย Google Maps

## ความสามารถ

- 📍 **เลือกตำแหน่งได้หลายแบบ**: ใช้ GPS ของเครื่อง, พิมพ์ชื่อสถานที่ (เช่น “บางนา”, “อ.เมืองขอนแก่น” หรือพิกัด `13.75, 100.50`),
  เลือกเมืองจากรายการ, ปักหมุดบนแผนที่, ลากหมุดสีแดง หรือเลื่อนแผนที่แล้วกด “ค้นหาในบริเวณนี้”
- 📏 **กำหนดระยะค้นหา** 1, 3, 5, 10, 20, 30 กม. พร้อมวงรัศมีบนแผนที่
- 🧱 **10 หมวดสินค้า** (เลือกได้หลายหมวด): วัสดุทั่วไป, ห้างวัสดุ, ปูน/คอนกรีต/อิฐ/ทราย, เหล็ก, ไม้, กระเบื้อง/สุขภัณฑ์, สี,
  ไฟฟ้า/ประปา, ประตู/หน้าต่าง/หลังคา, เครื่องมือ/เช่าเครื่องจักร
- 📞 **ช่องทางติดต่อ**: กดโทรได้ทันที, LINE, Facebook, เว็บไซต์, อีเมล, นำทาง, แชร์ข้อมูลร้านเข้าแชต
- 🔎 ร้านที่ยังไม่มีเบอร์ มีปุ่ม “หาเบอร์” (ค้น Google) และ “แก้ไขข้อมูล” (เพิ่มเบอร์ลง OpenStreetMap)
- ♡ **บันทึกร้านโปรด** ไว้ดูภายหลัง
- 🏬 **ห้างวัสดุทั่วประเทศ** (ไทวัสดุ, โฮมโปร, โกลบอลเฮ้าส์, ดูโฮม, บุญถาวร, เมกาโฮม) พร้อมปุ่ม “หาสาขาใกล้ฉัน”
- ＋ **เพิ่มร้านของคุณ** — บันทึกในเครื่อง แล้วกด “คัดลอกข้อมูลร้าน” เพื่อส่งให้ผู้ดูแลเว็บเพิ่มเป็นร้านพันธมิตร
- 🔗 ลิงก์บนแถบที่อยู่จำตำแหน่ง/ระยะ/หมวดไว้ ส่งให้คนอื่นเปิดดูผลเดียวกันได้
- 📱 ใช้ได้ทั้งมือถือ (สลับ รายการ/แผนที่) และคอมพิวเตอร์ (รายการคู่แผนที่)
- ⚡ **ค้นหาทันที**: ข้อมูลร้านทั่วประเทศสร้างไว้ล่วงหน้าใน `data/` (อัปเดตอัตโนมัติทุกสัปดาห์) เว็บโหลดเฉพาะช่องพื้นที่ที่ค้นหา
  จึงไม่ต้องรอเซิร์ฟเวอร์แผนที่ ถ้าต้องการข้อมูลสด กด “ดึงข้อมูลล่าสุด” (ถ้าเซิร์ฟเวอร์ช้าเกิน 6 วินาทีจะลองเซิร์ฟเวอร์สำรองพร้อมกัน)

## ข้อมูลร้านมาจากไหน

| แหล่ง | รายละเอียด |
| --- | --- |
| `data/` สร้างจาก [OpenStreetMap](https://www.openstreetmap.org) (ไฟล์ประเทศไทยของ [Geofabrik](https://download.geofabrik.de/asia/thailand.html)) และ [Overture Maps Places](https://docs.overturemaps.org/guides/places/) | แหล่งหลัก ค้นหาได้ทันที สร้างใหม่ทุกสัปดาห์ด้วย GitHub Actions ร้านที่ซ้ำกันสองแหล่งจะรวมเป็นรายการเดียว และเติมเบอร์โทร/เพจ Facebook จาก Overture ให้ |
| [Overpass API](https://overpass-api.de) | ดึงสดเมื่อกด “ดึงข้อมูลล่าสุด” หรือเมื่อยังไม่มีโฟลเดอร์ `data/` |
| `js/stores-data.js` | **ร้านพันธมิตร** ที่ผู้ดูแลเว็บยืนยันแล้ว แสดงพร้อมป้าย “✔ ร้านพันธมิตร” |
| เบราว์เซอร์ของผู้ใช้ (localStorage) | ร้านที่ผู้ใช้เพิ่มเองและร้านที่บันทึกไว้ เห็นเฉพาะในเครื่องนั้น |

ค้นหาชื่อสถานที่ใช้ [Nominatim](https://nominatim.org) และแผนที่ใช้ [Leaflet](https://leafletjs.com) (อยู่ใน `vendor/leaflet`)

## โครงสร้างไฟล์

```
index.html          หน้าเว็บ
css/style.css       หน้าตาเว็บ
js/config.js        ตั้งค่า: หมวดหมู่ คำค้น จังหวัดลัด ห้างวัสดุ เซิร์ฟเวอร์แผนที่
js/stores-data.js   รายชื่อร้านพันธมิตร (แก้ไฟล์นี้เพื่อเพิ่มร้าน)
js/app.js           การทำงานทั้งหมดของเว็บ
data/               ข้อมูลร้านทั่วประเทศ แบ่งเป็นช่อง 0.1° (สร้างอัตโนมัติ ห้ามแก้ด้วยมือ)
scripts/build_data.py              สคริปต์สร้าง data/ จากไฟล์ OpenStreetMap
.github/workflows/update-store-data.yml  สั่งสร้าง data/ ใหม่ทุกวันจันทร์
vendor/leaflet/     ไลบรารีแผนที่ Leaflet 1.9.4
```

ไม่ต้อง build ไม่ต้องติดตั้งอะไร เป็นไฟล์ HTML/CSS/JS ล้วน

## วิธีเปิดใช้งาน

### ทดลองในเครื่อง

```bash
python3 -m http.server 8000
```

แล้วเปิด <http://localhost:8000> (ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ ไม่ใช่ดับเบิลคลิกไฟล์ เพื่อให้ GPS ทำงาน)

### เผยแพร่ฟรีด้วย GitHub Pages

1. ไปที่ **Settings → Pages** ของ repository นี้
2. ที่ **Build and deployment** เลือก Source เป็น **Deploy from a branch**
3. เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด Save
4. รอสักครู่ เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/MATERIX/`

> GPS ของมือถือใช้ได้เฉพาะเว็บที่เป็น `https://` ซึ่ง GitHub Pages รองรับอยู่แล้ว

## เพิ่มร้านพันธมิตร

เปิด `js/stores-data.js` แล้วเพิ่มร้านตามรูปแบบนี้:

```js
window.MATERIX_STORES = [
  {
    id: 'partner-001',
    name: 'ชื่อร้าน',
    cats: ['general', 'steel', 'rental'],   // id หมวดจาก js/config.js
    phones: ['02-xxx-xxxx', '08x-xxx-xxxx'],
    line: '@shopname',
    facebook: 'https://www.facebook.com/shopname',
    website: 'https://shop.example.com',
    address: 'ที่อยู่',
    hours: 'จ.-ส. 07:30-17:30',
    note: 'สินค้า/บริการเด่น',
    lat: 13.7563,
    lng: 100.5018
  }
];
```

ถ้าร้านกรอกข้อมูลผ่านปุ่ม “เพิ่มร้านของคุณ” บนเว็บ แล้วกด “คัดลอกข้อมูลร้าน” จะได้ข้อมูลรูปแบบนี้พร้อมวางได้ทันที

## ปรับแต่ง

- **หมวดหมู่และคำค้นในชื่อร้าน**: แก้ `categories` ใน `js/config.js`
- **หมวดของ Overture ที่นับเป็นร้านวัสดุ**: แก้ `CATEGORY_TAGS` / `NAME_RULES` ใน `scripts/overture.py`
  (log ของ workflow “Update store data” มีรายงานจำนวนร้านในแต่ละหมวดที่พบ ว่าหมวดไหนถูกเก็บหรือข้าม)
- **จังหวัดในรายการลัด**: แก้ `cities`
- **ห้างวัสดุ / เบอร์ Call Center**: แก้ `chains` (ตอนนี้ใส่เบอร์เฉพาะไทวัสดุ 1308 และโฮมโปร 1284 ที่ยืนยันจากประกาศของบริษัทแล้ว)
- **ระยะค้นหาเริ่มต้น / จุดเริ่มต้น**: แก้ `defaultRadiusKm` และ `defaultCenter`

## อัปเดตข้อมูลร้าน

ข้อมูลใน `data/` สร้างใหม่อัตโนมัติทุกวันจันทร์ ถ้าต้องการอัปเดตทันที ไปที่แท็บ **Actions → Update store data → Run workflow**

สร้างเองในเครื่องก็ได้:

```bash
pip install osmium duckdb
```

```bash
curl -fLo thailand.osm.pbf https://download.geofabrik.de/asia/thailand-latest.osm.pbf
```

```bash
python3 scripts/build_data.py thailand.osm.pbf data
```

## ข้อควรรู้

- เซิร์ฟเวอร์ Overpass, Nominatim และ tile ของ OpenStreetMap เป็นบริการฟรีที่มีโควตาการใช้งาน
  เหมาะกับเว็บที่มีผู้ใช้ไม่มาก ถ้าผู้ใช้เยอะขึ้นควรเปลี่ยน `tileUrl` / `overpassEndpoints` / `nominatimUrl` ใน `js/config.js`
  ไปใช้ผู้ให้บริการแบบเสียเงินหรือเซิร์ฟเวอร์ของตัวเอง
- ข้อมูลใน OpenStreetMap มาจากผู้ใช้ทั่วไป อาจไม่ครบหรือไม่เป็นปัจจุบัน ควรโทรยืนยันกับร้านก่อนเดินทาง
- ทุกคนช่วยเพิ่มเบอร์โทร/ร้านใหม่ใน OpenStreetMap ได้ และเว็บนี้จะแสดงข้อมูลใหม่โดยอัตโนมัติ
